# React intro

This directory contains the React introduction exercises for the `alu-web_react`
repository.

## Projects

- `task_0` starts the basic School dashboard.
- `task_1` adds expressions, utility functions, and notifications.
- `task_2` adds the login form and notification priorities.
- `task_3` adds Enzyme and React component tests.
- `task_4` contains the GitHub Pages deployment setup.
- `task_5` contains the Webpack, Babel, reorganized source, and final tests.

Install dependencies inside the task you want to run, then use that task's
`start`, `build`, or `test` script as appropriate.
