# React Props

This project builds the React props exercise progressively from component extraction through reusable, prop-validated course and notification components.

Each task is an independent dashboard under `task_N/dashboard`:

- `task_0`: split the dashboard into Header, Footer, Login, and Notifications components.
- `task_1`: add component-focused Enzyme tests.
- `task_2`: extract reusable NotificationItem components.
- `task_3`: React DevTools review artifacts.
- `task_4`: add prop types, default props, CourseList, and notification drawer behavior.
- `task_5`: add shapes, dynamic course and notification lists, and edge-case tests.

To run a task, enter its directory, install dependencies, and run `npm test` or `npm run test-watch`.
